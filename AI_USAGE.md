# AI Usage Guide

## Model
- Model: `llama-3.3-70b-versatile`
- Provider: Groq API

## Prompt Design
The application uses Groq AI to analyze resumes, evaluate ATS alignment, generate interview questions, coach responses, and create career guidance.

## Limitations
- Output quality depends on uploaded content and prompt quality.
- Network and API availability can impact response times.
- Generated advice should be reviewed before being used in high-stakes hiring decisions.

## Responsible AI
Treat the generated feedback as a coaching aid rather than a guarantee of hiring success.
